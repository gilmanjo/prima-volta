Prima Volta — design figures

Concept diagrams and computed hypothetical outcomes. Every chart below is generated by a seeded mini-simulation running the suite's documented mechanics and constants — bands 95/85/70, the 10-entry window (act at 5), 3-entry cooldowns, 40 points per ladder position, gate-release streaks, the 2× prescription threshold. In the testing doc's spirit (13-TESTING): these are the machine's consequences, not illustrations of wishes. (One deliberate light look; a communication artifact like the mockups, never shipped.)

Toolchain: edit docs/figures/src/, run node build.mjs — never the built file. Charts follow the data-viz method (validated categorical trio, single-hue series, hairline grid, direct labels + legends, native hover titles, data tables); the seeded simulations implement the difficulty controller (05-DIFFICULTY §3), the gate streaks (02-ITEM-MODEL §1), and the rating formulas (07-RATINGS §3) verbatim, with a simple ground-truth learner per the testing doc (13-TESTING §2).
