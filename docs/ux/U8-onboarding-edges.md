# U8 · Onboarding & edge states

First contact, and everything that can go sideways mid-practice.

**Mockup:** [mockups/U8-onboarding-edges.html](mockups/U8-onboarding-edges.html)

## First run

1. **Welcome** — one screen, the thesis in one sentence, no tour.
2. **Device setup** — detect Web MIDI → calibration ritual (U7) — or "no keyboard right now" → knowledge-only mode, invited to return.
3. **Placement** — the benchmark at reduced length (05 §3 / 07 §5: ~6 excerpts + two flash probes, one-glance previews, ~2 minutes). **Prominently skippable** — skipping seeds every axis at F-- and lets the staircase run; nobody is forced into a test on minute one. Copy frames it as "find your starting line," not a test.
4. **Map reveal** — the seeded skill profile and the (mostly unlit) map, with one CTA: the starter template.

## Edge states

| Situation | Behavior |
|---|---|
| No MIDI device on launch | Knowledge-only mode (U1): map filters to choice-answerable; a quiet "connect a keyboard" affordance, no nagging |
| Device disconnects mid-drill | Current item voided (not graded), banner offers reconnect or knowledge-only mode; the bout stays open per 08 §6's timeout |
| Disconnect mid-read | Rehearsal: the partial is simply not scored (03 §7 spirit). Performance: attempt discarded with a one-line apology — never scored-as-broken |
| BLE jitter above threshold | U7's warning line at performance entry; windows widen automatically (03 §3) |
| Fully-bright area | The polishing banner (U2) with frontier/neighbor offers |
| Day-one map | Mostly unlit + starter CTA (U1); unintroduced ≠ work |
| Mid-bout scope change | Takes effect at the next served item; no retroactive anything |
