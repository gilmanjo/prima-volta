# U5 · Library — catalog browser & templates

The reference shelf: browse everything the app can drill, and author how practice is structured.

**Mockup:** [mockups/U5-library.html](mockups/U5-library.html)

## Catalog browser

- **The eleven families** → variants & stages → drills. Per-drill row: strength pip, stage name (plain words, never T-numbers), gate progress (window-achievement dots), last-practiced.
- The **admission frontier is visible**: unlit-outline rows labeled "up next" — the curriculum is inspectable, never a mystery (02 §7's seed ladders, rendered; the wave itself stays model-internal).
- Row actions: **Practice now** (single-atom sovereignty, 08 §4) · a scope shortcut ("hide this / show this") deep-linking into U7's scope section.
- Engine-C families show their generation story instead (axis positions + "start a read").

## Templates

- **List:** the starter template (pre-seeded, editable like any other) + user templates. Run · duplicate · edit. Sharing is a later-phase affordance (templates are JSON, 08 §5).
- **Editor:** block rows, drag-to-reorder. Per block: an **area selector** (family chips for the common case; an "advanced" sheet for domain / key region / tier range / single atom / weakest-anywhere / reading / prescription / benchmark), a **bound stepper** (open · minutes · count), and mode hints (reading mix slider defaulting 3:1; metronome pin).
- Editing is always safe: templates are data; running a stale template just serves whatever the filler decides today (counts honesty applies to any numbers the editor shows).
